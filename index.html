osu! AHR Commands

Interactive command reference for the Auto Host Rotation bot.

Statistics

Command Alias Description
!playtime !pt Shows your total tracked playtime and matches played.
!playstats !ps Shows matches played and number of #1 finishes.
!lastplayed !lp Shows when the current map was last played.
!maprecord !mr Shows the best recorded score on the current map and the player who set it.
!leavecount !lc Shows how many players left after the previous map.
!mapstats !ms Shows the current map's play count, leave rate, best score, and last played time.
!maptags !mt Shows the current map's stored tags. If none exist, the bot fetches official difficulty-specific tags from the osu! API.
!maptags add <tag> — Authorized users can add a tag to the current map.
!maptags remove <tag> — Authorized users can remove a tag from the current map.
!rs — Looks up your most recent score for the lobby's game mode, including mods, accuracy, combo, misses, and accurate FC pp.
!bms — Shows your best score on the current map.
!pp [mods] — Calculates 100%, 98%, and 95% FC performance points (pp) and star rating for the current map. Supports optional mods (e.g. !pp hr, !pp hdhr, !pp dt, !pp fl). Defaults to NM.
!rank — Shows your current global rank in the lobby's game mode.

Host Queue

Command Alias Description
!queue !q Shows the current host queue.
!autoskip on/off !as Turns AutoSkip on or off for yourself.
!setqueuepos <player> <position> !sqp Authorized users can move a player already in the host queue to a specified position.
*reorder <order> *order Authorized users can reorder the host queue.
*denylist add/remove <name> — Authorized users can add or remove a player from the queue deny list.

Match Control

Command Alias Description
!start — The host can start immediately. Non-host players can use it to vote start.
!start <seconds> — The host or an authorized user can start a countdown timer (e.g. !start 30).
!stop — The host or an authorized user can stop an active start countdown timer.
!abort — Votes to abort an in-progress match. The host, authorized users, or referees abort immediately in 1 command.
*start — Authorized-only immediate match start.
*abort — Authorized-only immediate match abort (cancels immediately without voting).

Map Selection & Rules

Command Alias Description
!rd [category] !random [category] Picks a random map from the configured osu!Collector collections. Without a category, all configured collections are used. With a category, only that category's collection pool is used.
!regulation !r Shows the current lobby regulation rules (star rating limits, max length, etc.).
!update — Updates the currently selected beatmap to the latest version on osu!. Useful if the host picked an outdated version.
!mirror — Provides alternative BeatConnect.io and Kitsu.moe download mirror links for the currently selected map.

Host Skipping

Command Alias Description
!skip !s Votes to skip the current host. The host can use it to skip themselves immediately. Players cannot vote twice.
!skip <host> — Can be used to target the current host when the supplied name matches the host.
*skip !forceskip / !fs Authorized users can immediately skip the current host.
*skipto <username> !sethost <username> Authorized users can skip to a specific player who is currently in the lobby.

Match Time

Command Alias Description
!timeleft !tl Shows the remaining time in the currently running match.

Moderation

Command Alias Description
!ban <name> <days> — Authorized-only temporary ban. Banned players are automatically kicked when they join.
!pban <name> — Authorized-only permanent ban.
!pardon <name> — Authorized-only removal of a ban.
!banmapset <id> — Authorized-only ban of a specific beatmapset from being picked.
!unbanmapset <id> — Authorized-only removal of a beatmapset ban.
!addref [player] — Authorized-only command to grant Bancho referee status to yourself or the specified player.
!rmref <player> !removeref Authorized-only command to remove Bancho referee status from a player.

Lobby Management (Authorized)

Command Alias Description
*keep size <1-16> — Locks and enforces the lobby player capacity to the specified size.
*keep mode <team> <score> — Locks and enforces the lobby team and score mode (e.g. headtohead scorev2).
*keep mods <mods> — Locks the lobby active mods (e.g. *keep mods freemod).
*keep password [password] — Sets and locks the room password (leave blank for no password).
*keep title <name> *keep name Locks and enforces the room title name.
*no keep <setting> — Disables keeping mode, size, mods, password, or title.
*clear *clearcache Manually clears cached beatmap files and history from memory.

Automation & Rules (Authorized)

Command Alias Description
*regulation <key>=<val> — Modifies rules live in chat. Supported keys: star_min (or diff_min), star_max (or diff_max), length_min, length_max, num_violations_allowed, gamemode.
*regulation enabled / disabled — Toggles regulation limit checks on or off.
*regulation allow_convert disallow_convert Allows or disallows converted beatmaps.
*no regulation — Completely disables all regulation checking in the room.
*mapchecker_enable / disable — Enables or disables the MapChecker plugin.
*autostart_enable / disable — Enables or disables the automatic match start timer when a map is picked.
*autostart_time <seconds> — Sets the countdown duration for the auto-start timer (e.g. *autostart_time 30).
*autostart_clearhost_enable disable Toggles clearing host if the host does not pick a beatmap.
*afkkick_enable / disable — Enables or disables automatic kicking of AFK players.
*afkkick_threshold <count> — Sets how many consecutive rounds a player can be AFK before being kicked.
*afkkick_cooltime <ms> — Sets the cooldown in milliseconds for the AFK kicker.
