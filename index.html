osu! multiplayer utility bot

Command Reference

Commands available in the osu! Auto Host Rotation Bot, including player statistics, map history, host queue controls, match starting, random map selection, and moderation.

Quick help: Type !help in the lobby to display the bot's command list. Some commands are restricted to authorized users.

Statistics

!playtime!pt
Shows your total tracked playtime and the number of matches you have played.
!playstats!ps
Shows how many matches you have played and how many first-place finishes you have recorded.
!lastplayed!lp
Shows how long ago the currently selected map was last played.
!maprecord!mr
Shows the highest recorded score on the currently selected map and the player who achieved it.
!leavecount!lc
Reports how many players left after the previous map.
!mapstats!ms
Shows the current map's play count, historical leave rate, best score, and last-played time.
!maptags!mt
Displays tags associated with the current map. If no stored tags exist, the bot attempts to retrieve related community tags.

Map Tags

!maptags add <tag>
Adds a tag to the current map.
Authorized users only
!maptags remove <tag>
Removes a tag from the current map.
Authorized users only

Host Queue

!queue!q
Displays the current host queue.
!autoskip on
Marks yourself to be automatically skipped when your turn to host is reached.
!autoskip off
Disables AutoSkip for yourself.
!setqueuepos <player> <position>!sqp
Moves a player already in the host queue to the specified queue position.
Authorized users only

Match Control

!start
Starts the match if you are the host. Otherwise, it participates in the start-vote mechanism. With a numeric argument, the host or an authorized user can start a countdown timer.
!stop!abort
Cancels an active bot-managed match start timer.
Host or authorized users

Map Selection

!rd [category] !random

Selects a random map from the configured osu!Collector collections. Without a category, all configured collections are used. With a category, only that category's collection pool is used.

Configured categories
jumptechaimanime streamchillbangervocaloid kpop5starlow_arhard_rock touhoufarmmememikujpop
  • Category names are case-insensitive.
  • Misspelled category names receive a closest-match suggestion when the match is close enough.
  • The selected map must fit the current MapChecker star range.
  • The bot checks up to 15 random candidates and skips deleted or unavailable maps.
  • Only the current host or an authorized user can use the command.
!rd!random
Selects a random map. An optional category can be supplied to restrict the random selection.

Moderation

!ban <name> <days>
Creates a temporary ban for the specified number of days. Banned players are automatically kicked when they join.
Authorized users only
!pban <name>
Permanently bans a player. The ban remains active until removed.
Authorized users only
!pardon <name>
Removes an existing ban from a player.
Authorized users only

Help

!help
Displays the bot's built-in command list, grouped into statistics, queue, and map commands.
